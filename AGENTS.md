# Project guidance

- Read [`.claude/CLAUDE.md`](.claude/CLAUDE.md) before working in this repository. It is the source of truth for project conventions.
- For a task covered by a workflow in [`.claude/skills/`](.claude/skills/), read the relevant `SKILL.md` and follow it from its existing location.
- Treat `.claude/` as read-only. Create, edit, move, rename, or delete anything inside it only after the user explicitly authorizes that change to `.claude/`. Permission to perform a related task does not authorize changes there. This also applies to indirect changes through scripts, tools, or symlinks.
